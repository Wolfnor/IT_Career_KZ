IT Career KZ — website project

1. Extract the ZIP archive.
2. Open index.html to view the website.
3. Open HTML, CSS and JS files in Visual Studio Code to read or edit the code.

For full video seeking support, open the folder with VS Code Live Server.
Alternatively, run: python -m http.server 8000
Then open http://localhost:8000 in your browser.

Files:
index.html — page structure
style.css — design and animations
script.js — search, filters, statistics and charts
data.js — job records
i18n.js and translations.json — interface translations
carousel.js — photo banner
sounds.js — click sound
guide.js — browser voice guide
video.js — video loading and audio coordination
results.csv — original dataset
assets/ — photos, logo, click sound and introduction video

The voice guide depends on voices installed in your browser and operating system.
The extra video slider and 5-second buttons have been removed in this version.
